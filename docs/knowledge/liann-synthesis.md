# PLAN-OF-ATTACK — Pathfinder rebuild (Liann's primed audit, Phase 5 synthesis)

Date: 2026-08-06. Evidence base: `audit/liann/` — 21 unit reports, 8 knowledge harvests, 6 lanes,
29 adversarial verify verdicts (Phase 4 is authoritative over Phase 2/3 where they disagree).
North star: **org/pro IDs in → intelligent themes out → LCM tool.** Code is truth; docs are claims.

---

## 1. Summary

The repo can hit the core goal today, with two asterisks: the golden path (Vercel → Railway viewer → action-console loop →
persona-cards scoring → Supabase → Sheet/LCM POST) is real and verified hop-by-hop (lanes/L1-golden-path-trace.md §1), but the
export leg is a manual CLI invisible to the operator (units/U10s.md N2) and the audience index needs a laptop-SSO Snowflake
refresh (lanes/L4-config-infra.md §3.3). Three biggest problems: (1) serial ~6–10-LLM-call-per-idea runs, no caching or client
reuse, cost=None by default, silent degradation to canned ideas (verify/concern-C6.md, C7.md); (2) a population-of-one greedy
loop, any-improvement keep bar, no cross-run memory (verify/concern-C8.md); calibration magnitude lift still unproven
(verify/concern-C2.md Claim 9); (3) ~43% of `src/` import-dead; Supabase a mandatory middle tier — production cannot reach
Snowflake (lanes/L3, L4, verify/concern-C15.md). Three most valuable assets: (1) the learned Exit-A calibration + fit pipeline
+ the fail-closed persona stack (units/U2.md, U3.md); (2) the loop's Karpathy decision protocol, single-sourced ranking,
screen-then-confirm gating (verify/concern-C10.md, C5.md Claim 19); (3) the built export leg + org-context allowlist contract + the 846-test spec suite (units/U10x.md, lanes/L2 §2, units/U13.md, U14.md).
